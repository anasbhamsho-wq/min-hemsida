Olika bildformat

Klassiska rasterformat (Universellt stöd)

  • .jpg / .jpeg: Bäst för fotografier och komplexa bilder med många färger. Stöder inte transparens.
  • .png: Perfekt för logotyper, grafik och bilder som kräver genomskinlig bakgrund (transparens).
  • .gif: Används främst för enkla, rörliga animationer. Stöder endast 256 färger.

Moderna standardformat (Rekommenderas)

  • .webp: Ger mycket hög bildkvalitet med liten filstorlek.
  • .avif: Ett nyare format som ger bra komprimering och hög kvalitet.

Vektorformat (För skalbar grafik)

  • .svg: Används för ikoner, logotyper och illustrationer. Bilden kan förstoras utan att förlora skärpa.
